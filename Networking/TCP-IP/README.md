# TCP/IP

## TCP/IP Model
- Application Layer
- Transport Layer
- Internet Layer
- Network Access Layer

## TCP vs UDP

**TCP**
- Reliable
- Connection-oriented
- Used for HTTP, HTTPS, SSH, Email

**UDP**
- Faster
- Connectionless
- Used for Gaming, VoIP, Streaming

## TCP Three-Way Handshake

1. SYN
2. SYN, ACK
3. ACK

After the handshake, data transfer begins.
